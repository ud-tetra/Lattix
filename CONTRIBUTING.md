# Contributing to Lattix R&D

Start with [BOOTLOADER.md](BOOTLOADER.md). Register a public contributor profile, choose a scoped task, create a unique session, acquire ownership and work on an isolated branch. Include evidence boundaries, source versions, actual checks, immutable artifacts and a handoff in your PR.

```bash
python3 scripts/validate.py
python3 -m unittest discover -s tests -v
```

Preserve negative findings and frozen runs. Do not copy secrets or private chat archives. Promotion and marketing claims require scoped evidence review; CI is not a product certification. See [administration](docs/ADMIN_SETUP.md) for the separation between repository convention and server enforcement.
